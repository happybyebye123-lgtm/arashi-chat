# Arashi Chat v4
Mobile-first PWA for iPhone. Deploy this project to Vercel, set OPENAI_API_KEY in Environment Variables, then open the deployed URL in Safari and choose Share → Add to Home Screen. The phone never receives the API key.

The app has a local fallback if no backend URL is configured. To use the real AI endpoint, open ⚙︎ and set `https://YOUR-DOMAIN/api/chat`.
